# Криптовалютный аналитический дашборд "Воровское казино"

Этот проект представляет собой десктопное приложение для анализа криптовалютного рынка в реальном времени, разработанное на Python с использованием CustomTkinter.

Приложение отслеживает цены на бессрочные фьючерсы с биржи Bybit, цены на BTC с Binance и Bybit, а также данные о капитализации с CoinGecko.

## Ключевые особенности

- **Дашборд в реальном времени:** Отображение цен на BTC и данных по множеству других монет.
- **Динамические индикаторы:** Расчет и отображение процентного изменения цены за различные периоды (5м, 15м, 1ч, 24ч и т.д.).
- **Интерактивная таблица:** Все данные по монетам представлены в таблице с возможностью сортировки по любому столбцу.
- **Анимация тренда:** "Воровская звезда" в углу вращается, указывая на направление тренда цены BTC за последние 30 секунд.
- **Локальная база данных:** Скрипт сохраняет историю цен в локальную базу данных SQLite, что позволяет в будущем реализовать анализ исторических данных и восстановление после сбоев.
- **Алгоритм поиска сигналов:** Включает в себя продвинутый (но пока экспериментальный) модуль для поиска шорт-сигналов на основе технического анализа.

## Установка

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL вашего репозитория>
    cd <папка репозитория>
    ```

2.  **Создайте и активируйте виртуальное окружение** (рекомендуется):
    ```bash
    python -m venv venv
    # Windows
    venv\Scripts\activate
    # macOS / Linux
    source venv/bin/activate
    ```

3.  **Установите необходимые зависимости:**
    Все зависимости перечислены в файле `requirements.txt`. Установите их с помощью pip:
    ```bash
    pip install -r requirements.txt
    ```

## Запуск приложения

Для запуска приложения выполните следующую команду в терминале, находясь в корневой папке проекта:

```bash
python main.py
```

При первом запуске может потребоваться некоторое время для загрузки всех необходимых данных (например, списка монет с CoinGecko).

## Структура проекта

- `main.py`: Главный файл для запуска, выполняет роль контроллера.
- `requirements.txt`: Список зависимостей.
- `src/`: Папка с исходным кодом.
  - `api/client.py`: Модуль для взаимодействия с API бирж.
  - `db/`: Модули для работы с базой данных (модели и менеджер).
  - `gui/app.py`: Модуль, отвечающий за весь графический интерфейс.
  - `analysis/`: Модули для расчетов (калькулятор) и торговой стратегии.
- `crypto_data.db`: Файл базы данных SQLite, который будет создан автоматически при первом запуске.
